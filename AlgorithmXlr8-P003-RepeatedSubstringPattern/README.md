# Repeated Substring Pattern

**Difficulty:** `Easy`

## Problem

Given a string s, check if it can be constructed by taking some substring of it and appending multiple copies of that substring together.

Read s from standard input, and print true or false to standard output.

## Examples

### Example 1

**Input**
```
abab
```
**Output**
```
true
```

**Explanation:** abab is ab repeated twice.

### Example 2

**Input**
```
aba
```
**Output**
```
false
```

**Explanation:** There is no substring that, repeated some number of times, reconstructs aba.

### Example 3

**Input**
```
abcabcabcabc
```
**Output**
```
true
```

**Explanation:** abcabcabcabc is abc repeated four times.

# Find the Index of the First Occurrence in a String

**Difficulty:** `Easy`

## Problem

Given two strings needle and haystack, return the index of the first occurrence of needle in haystack, or -1 if needle is not part of haystack.

Read haystack on the first line and needle on the second line of standard input, and print the index (or -1) to standard output.

## Examples

### Example 1

**Input**
```
sadbutsad
sad
```
**Output**
```
0
```

**Explanation:** sad first appears starting at index 0.

### Example 2

**Input**
```
leetcode
leeto
```
**Output**
```
-1
```

**Explanation:** leeto never appears as a contiguous substring of leetcode.
